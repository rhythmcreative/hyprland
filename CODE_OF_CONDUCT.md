# Code of Conduct

This setup is something I've spent a lot of time building, tweaking, and using every day. I share it publicly so anyone interested can use it, adapt it, or learn from it.

The community guidelines here are simple and grounded in common sense:

### Be decent to each other
Treat people with respect. It doesn't matter if someone is compiling custom kernels or trying out a tiling window manager for the very first time. We all started knowing nothing.

### No elitism or gatekeeping
There is no room for distro wars or looking down on what tools someone chooses to use. Arch, Debian, Fedora, Ubuntu, Alpine, openSUSE, and NixOS are all welcome here. If someone asks a basic question, answer it patiently or leave it for someone else to help. Avoid unhelpful replies like "just read the manual".

### Constructive feedback
If you review someone's pull request or discuss a configuration choice, focus on the code and the technical reasons. Don't make it personal.

### Zero tolerance for harassment
Insults, discriminatory remarks, trolling, harassment, or publishing private information will not be tolerated.

### Handling issues
If you run into behavior that crosses these lines, reach out to me privately via GitHub or by email at `rhythmcreative@users.noreply.github.com`. I'll look into it directly and take whatever action is needed to keep things fair and comfortable for everyone.
